3 · Small — compact table rows, and nowhere else

A tighter box, not smaller type. The label stays 14px: a caption-size control sitting in body-size copy reads as a rendering fault rather than as hierarchy. One job only — a compact table row. Anything on a shared line takes plain .btn: page head, card head, form bar, toolbar, filter bar, all beside .control / .menu-btn / .seg at the same 34px. .btn--sm exists to stay near the 22.4px line of text it rides inside .tbl--compact, which is itself opt-in. Reaching for --sm is never a reason to make a table compact — that inversion spread it across five pages in one sitting, which is why the rule is this narrow (owner call 2026-07-29). This page previously read "card headers, table rows, toolbars" and contradicted buttons.css; corrected 2026-07-30 after the Codex audit.

5 · Fill colors — these are the tokens the buttons actually use

accent-fill #4068CA — primary neg-fill #C4372C — danger neg #FF5F56 — dot only, never a fill

The two fills do not invert. A fill carries its own contrast, so it never moves between modes — white text has to keep sitting on it. The text tokens do move: --accent lifts to #6E9BF0 on dark so links stay readable. Reaching for the text token to paint a fill is what turned the destructive button into a pale salmon slab louder than the primary (tokens.css, 2026-07-29). Hexes are written out here precisely because these two are mode-invariant.
