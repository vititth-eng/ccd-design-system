ตาราง v2 — ทุกแบบในที่เดียว

One flush base, mixed by need. Two control gutters: leading = select-checkbox / expand-chevron · trailing = kebab ⋯ (row actions). Headers can carry sort + type-aware filter. Stack only what a screen needs — most tables are flat.

1 · Flat — label / value
no controlsbold first col
Feasibility · assumptions, Onboarding · settings. Read-only reference. First column is the label (600/ink), value reads right. English gloss drops under the Thai via .cell-en. No header chrome — nothing to sort.
พารามิเตอร์ค่าหน่วย
2 · Status board
flatType-1 dot
Landing · tool status, DISC · session state. At-a-glance, no actions. Status uses the bare .status dot (Type 1) — never the fill pill inside a cell (doctrine).
เครื่องมือสถานะผู้ใช้งาน
3 · Multiselect + kebab
lead: checkboxtrail: ⋯
Multi-Rater · manage rounds, Comms · recipient picker. Tick rows → bulk action; per-row ⋯ for edit/duplicate/delete. Select-all in the header (indeterminate when partial). Selected row gets a brand tint.
ชื่อรอบสถานะผู้ถูกประเมิน
4 · Sortable + filterable headers
header menufilter by type
360 · respondent list, Onboarding · survey responses. Big sets you scan + narrow. Click a header → sort asc/desc + a filter shaped by the column type: text contains · enum checkboxes · number range · date from/to. Dot = filtered, caret = sorted.
5 · Expand — nested child rows
lead: chevron--matrix
Feasibility · cash flow (year → quarter → month). Hierarchy that must stay column-aligned. Children live in the SAME table so numbers line up; open parent casts a shadow. Click row to expand — no page-nav, no breadcrumb.
ปีรายได้ต้นทุนกระแสเงินสด
6 · Matrix — compact + heat
--matrix--compactheat cells
360 · score grid, Sounding Board · response matrix. Dense numeric comparison. Equal fixed columns (--matrix), 12px cells (--compact), and heat fill maps magnitude (mono-blue --heat-1..5) so the eye finds highs/lows without reading every number.
ผู้ประเมินสื่อสารทีมเวิร์กภาวะผู้นำผลงาน
7 · Grouped — band rows
group band
Onboarding · rooming, 360 · by cohort. Section a list into buckets. The band carries label + count. Members are normal rows — same columns, no indent — so the list stays scannable across groups.
ชื่อ-สกุล สถานะ ทำแล้ว

Mix & match: 3+4 = manage a long list (select + sort/filter together). 5+6 = drill a numeric hierarchy (expand + matrix). 2+6 = status with heat. Controls compose because each owns a fixed gutter; they never fight for space.
