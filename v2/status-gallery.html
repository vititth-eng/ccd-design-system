4 · Strong text tier — a status hue read as TEXT / a NUMBER (not a dot). Passes AA on white.

Bright --pos/--cau/--neg are dot-only (fail AA as text). Use --pos-strong / --cau-strong / --neg-strong when a status hue must be read as text or a number: low-N counts, deltas, overdue days.

5 · Progress meter — a quantity, never a state

The meter never takes a status hue. A self-reported status and a computed progress bar are two signals allowed to disagree (a project can be 90% done and still at risk), so one colour would merge them. Accent only. Default width suits a table cell; .meter--wide is the card-header size.
