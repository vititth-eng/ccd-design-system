9 · Grants — set-valued access, one square per thing granted

Muted until granted, brand when granted. Fixed width, so a column of these does not reflow row to row — which is what lets an access matrix live inside a table cell. Use only where each option has a mark people recognise: apps, sections, resources. For company names, cohort slugs or role names there is nothing to draw — those take the checkbox menu (menu.css .menu__item with an <input type="checkbox">).

granted · granted · not granted · disabled

One size only. A .grants--sm (24px) existed until 2026-08-11 for dense table rows and no consumer ever used it — the compact table density it was built for was never turned on either. The row takes the 44px floor under pointer: coarse.

A ladder is not a set. Where the column is ordered — cowork's booking is one enum, none < rooms < rooms_car — the squares still render separately and the coupling lives in the handler. Joining them into one block reads as a segmented control, which promises "pick one of these".
