scope rule No tabs on this page — it's a detail screen, not a multi-section page. Breadcrumb carries "where am I in the hierarchy"; .nav stays the same. Tabs return when a section-switcher is actually needed.

anti-pattern avoided Never stack breadcrumbs + tabs at the same hierarchy level — the doctrine note in nav.css says active-state languages mustn't compete. Detail page = breadcrumbs. Section page = tabs. Not both.
