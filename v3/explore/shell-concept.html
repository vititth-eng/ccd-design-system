What this mock cannot do — and the real shell can

Every state in that grid is painted on with a class. Nothing is really hovered, really focused, or really disabled. Press Tab on this page and the focus ring lands wherever the browser decides, not where the component says.

The real shell renders the actual component, so Tab order, focus trapping, keyboard navigation and disabled behaviour are the component's own — which is the half of the design system that static HTML has never once verified.
