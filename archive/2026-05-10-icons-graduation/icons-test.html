Rules

Sizing: only 16 / 20 / 24. Default to 20. 16 inside dense tables or alongside --fs-small. 24 only in headers, empty states, and side rails.
Color: stroke is always currentColor. Set color on the parent (link, button, status line). Don't hardcode color: on .icon itself except in known semantic pairings (see status section).
Spacing with text: gap: var(--s-2) (8px) between icon and adjacent text. The vertical-align on .icon-* classes handles inline placement; for flex contexts, align-items: center is enough.
Don't restyle: no fills, no shadows, no rotation (except .spin on loader). If a glyph isn't right at 2px round-cap stroke, redraw it on Lucide's grid — don't bend the rule per icon.
Adding new icons: only with a concrete near-term use. Take from Lucide first; custom-draw only when Lucide genuinely lacks. Every icon is a maintenance contract — the cost of adding is paid forever.
