4 · Perspective pair — pick A, B, or C

Misty has no purple. The question: how do we encode three perspectives (NH / SP / MT) without inventing off-palette hues? Three options below, all visible side-by-side.

A — Three blues (deep / mid / soft)

No new tokens. NH = --brand-deep, SP = --brand, MT = --brand-soft. Risk: at 7px dot scale the difference between brand and brand-soft might blur, especially against the dashboard's cool backgrounds.

NH — New Hire SP — Self MT — Manager

Inline use: avg score across NH 4.2 / SP 3.8 / MT 3.1.

B — Two blues + one warm tan

Introduces ONE new token: --brand-warm: #8C6F2C (a misty-derived warm tan). NH = --brand-deep, SP = --brand, MT = --brand-warm. Maximum chromatic distance, minimum palette drift.

NH — New Hire SP — Self MT — Manager

Inline use: avg score across NH 4.2 / SP 3.8 / MT 3.1.

C — No color encoding · text + glyph only

Zero new tokens, zero risk. Perspective is carried by the 2-letter glyph alone. Works because the perspectives are known (anyone reading the dashboard already knows NH/SP/MT) — color is paying for nothing. Tradeoff: harder to scan one perspective across a dense table at-a-glance.

NHNew Hire SPSelf MTManager

Inline use: avg score across NH 4.2 / SP 3.8 / MT 3.1.

Decision needed. A, B, or C — pick before graduation. My read: B if you scan perspective often (real second hue earns its place); C if perspective is just metadata that sits next to the score.

11 · Anti-patterns & deferred

No off-palette hue tokens. Teal, purple, web-orange, web-red are forbidden. The dashboard layer's --alert-*, --steady-teal, --perspective-mt, --sent-*, --heat-score-* are deprecated and reskin to misty at Phase 2A.
No pie / donut charts. Same as v1.
No green-for-up. Magnitude not direction.
No two-bar alert. Multiple lows → switch to heatmap.
No inline-styled hex for chart fills. Propose a token, graduate, then consume.
No new chart-specific gray. --ink-muted covers neutral / missing / aligned.

Explicitly deferred to v2 (when a real consumer arrives)

Categorical palette beyond perspective pair. Wait for a real cohort/department breakdown.
Real sparklines / time-series. Reserve the spark* name.
Tooltip / legend / axis primitives. No SVG charts in flight.
Annotation / threshold lines. No consumer.
Number abbreviation (1.2k / 3.4M). Cohorts are small.

What to look for

  • Speed of read. Which heatmap lets you find the "workload row is bad" without thinking? That's the directional axis working.
  • Calmness on the surface. Does the ramp shout against paper-tint, or sit in the same room? C3 is calmest, C1 loudest.
  • Colorblind sanity check. Squint your eyes (or use a colorblind sim) — if s1 and s5 look the same, the ramp is failing. C1 is best-tested for this; C3 needs verification.
  • Categorical separability at dot scale. Look at the 7×7 dots in the multi-line legend — can you tell cat-1 from cat-2 from cat-4 at that size? On dashboards, dots get small.

§13 · Tier-2 inventory (proposed final scope)

Total 10 named tokens + 2 reference gradients. Each color earns its slot. Discipline rule: a new Tier-2 token requires a real chart in a real tool that can't be served by what's here or color-mix(). No speculative additions.

Two hues meeting at neutral. Sentiment neg/neu/pos · Δ vs baseline · score 1→5.

Aliases: --sd-pos=--sd-1, --sd-neu=--sd-3, --sd-neg=--sd-5. Score reuse: --score-1=worst=--sd-5, --score-5=best=--sd-1 (same ramp, reversed semantics).

2 · Categorical (limited) 3 tokens · discrete

Cool blue-purple subset of the sequential ramp — picks 3, 5, 7 with maximum perceptual distance within the family. Capped at 3 because adjacent steps of a cool-only ramp can't carry true categorical load past 3-4 series. If a tool needs team breakdown > 3, that's a Phase 1.18 question.

--perspective-nh#64aad5
--perspective-sp#7497e3
--perspective-mt#a279db

Where used: perspective tags, multi-line trend (NH/SP/MT lines), perspective legend dots. Not used for: team A/B/C breakdowns, region splits, anything with no fixed identity meaning.

3 · Sequential gradient only · no named steps

Ordered without a midpoint — cohorts over time, process stages, waves. Ships as gradient only, no discrete tokens. Pull N stops via color-mix() or SVG <linearGradient> stops when needed.

Token: --seq-gradient. Endpoints: #7cb6c1 (start) → #ba66cb (end). Example use: 8-quarter cohort heatmap, wave-1-to-wave-N trend bands.

4 · Alert Tier-1 reuse · 0 new tokens

Severity arrows, threshold breaches, oncall pulses. Alert is UI status, not data — so it stays on Tier-1 misty identity. This is the deliberate boundary: charts use Tier-2 paint, UI status uses Tier-1 paint.

--dot-positive#6B8C2C
--dot-caution#A67C1A
--dot-negative#B5564A

Subtle but important: the misty rust #B5564A is quieter than the Tier-2 --sd-5 rust-pink #de425b. That's intentional — alert pills should feel disciplined, chart fills can be louder. Anti-pattern: don't use --dot-negative as a chart fill, and don't use --sd-5 as a status pill.

5 · Gradient (continuous) 2 tokens · linear-gradient strings

For smooth fills — choropleth maps, KDE plots, progress shading, sparkline area fills. Derived from divergent + sequential endpoints — no new colors introduced.

--sd-gradient · divergent · green ↔ neutral ↔ rust

--seq-gradient · sequential · cool blue → purple

Compose anywhere: background: var(--sd-gradient) on a div fills it with the diverging axis. For SVG, use stops #488f31 / #f6f6f6 / #de425b in <linearGradient>.

Final tally

  • Tier-1 misty (identity): 22 tokens — unchanged
  • Tier-2 data (this phase): 5 divergent + 3 perspective + 2 gradients = 10 tokens total
  • Alert reuses Tier-1 — no new tokens for status colors
  • Categorical > 3 series — deferred to Phase 1.18 (or whenever a real tool needs it)

Compare: IBM Carbon ships ~30 data-viz tokens, Atlassian ~24. Ten is tight, on purpose. Each unused token would become a drift vector.

What to look for

  • Banner urgency. Does the "Action required" banner read as something you'd act on within 5 minutes, or something you'd notice tomorrow?
  • Calm canvas. Does any column make the whole page feel anxious? That's the loudness penalty — Carbon's signal cost.
  • Pill→banner consistency. The pills (top-right of each column) and the banners use the same token. If the pill feels right but the banner doesn't, that's the scale problem talking — case for Tier-1.5.
