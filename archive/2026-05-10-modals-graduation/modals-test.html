§6 · Behavior notes

Reference checklist before graduation.

  • Native <dialog> via showModal() — free focus trap, ESC, return-focus.
  • Backdrop click closes (added in JS). Use cancel event for unsaved-form guards.
  • Animation: --dur-base + --ease. Modal fades+rises 8px; sheet slides 24px from edge.
  • Backdrop tint: rgba(ink, 0.4) + 2px blur — restrained, not opaque.
  • Scroll lock: native dialog already disables body scroll via inert backdrop.
  • Z-stack: showModal() promotes the dialog to the browser top-layer, which beats any z-index. A normal toast container sits below — to surface a toast over an open dialog, render it inside the dialog or use the Popover API so it also enters the top-layer.
  • prefers-reduced-motion kills slide/pop animation.
