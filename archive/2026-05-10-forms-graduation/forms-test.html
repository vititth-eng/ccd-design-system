What B locks in
  • One row height — every focusable control is 36px. Matches toolbar rhythm (DESIGN-SYSTEM §8).
  • One type ramp — body in fields uses --fs-body, labels use --fs-small + --fw-semi, helper/error use --fs-small.
  • One focus rule — ring-only via --focus-ring-*. No border-color flips, no custom box-shadow.
  • One error signal — .is-error swaps border to --dot-negative; helper text becomes error text. No icon, no fill.
  • Hover discoverable — border lifts to --ink-muted on hover; ring still wins on focus.
  • Switch ≠ checkbox — switch for instant toggles (settings); checkbox for form submission ("apply on save").
  • Namespace — .f-control on input/select/textarea; .f-choice wraps checkbox/radio; .f-switch wraps switch. .f-field/__label/__help/__error compose all of them.
