Sandbox · Phase 1.14

Tables

Sortable list of records. Quiet chrome, content does the talking. Per §14.5 the row+header skeleton is already locked — this sandbox extends it with sort, select, row-actions, toolbar, sticky header, pagination, and in-table empty/loading.

Open questions for this round

  • Sortable caret reservation — caret hidden by default, fades in on hover, locks visible when active. Avoids width-jumping headers. ✅ proposed
  • Row actions visibility — fade in on row hover (current), or always-visible quiet icons? Current is quieter but discoverability is poorer.
  • Bulk-action bar style — currently brand-soft pill above the table replacing toolbar. Alternatives: ink dark bar (loud), or in-toolbar inline (quiet but cramped).
  • Pagination footer — inside the table border (current) vs outside. Inside reads as one object; outside scales better with sticky-header tables.
  • Sticky header shadow — currently --shadow-1 when scrolled. Overkill, or right? See "Sticky header" demo.
  • Empty inside table — full-width colspan cell using .empty-block, or a dedicated .tbl-empty with table-aware padding?
