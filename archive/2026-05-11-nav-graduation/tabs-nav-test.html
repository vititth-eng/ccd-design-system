Tabs · Breadcrumbs · Nav

Three navigation primitives, queued together because they share visual rules: active-state language, hover-treatment, focus-ring discipline. Pick one variant per primitive; the composite at the bottom shows the locked set together on a real-screen mock.

Tabs

Section switcher inside a page surface. Used for dashboard perspectives (NH / NN), settings panes, record detail panels. Three variants below.

Variant A · underline

Active panel content — Overview.

Underline. Lowest-chrome option; sits on its own rule line; scales from 2 to 8+ tabs; supports counts; works on any background. Default candidate.

Variant B · segmented pill

Active panel content — NH perspective.

Segmented pill. Reads as toggle; right for 2–4 short labels that name an axis (perspective, time range, view mode). Don't use for 5+ items or long labels — gets crowded.

Variant C · soft chip

Filtered content — All.

Soft chip. Reads as filter, not section. Right when "no chrome line" is the goal (sits inside a card). Overlaps with future filter-chip primitive — flagged as decision: tabs-chip OR filter-chip, not both.

Breadcrumbs

Hierarchy trail. Sits above page title. Three variants — chevron, slash, back-arrow.

Variant A · chevron

Tools Onboarding Cohort · 2026 Q2 Response 0247

Chevron. Conventional; reuses Tier-1 icon; clear directionality. Default candidate.

Variant B · slash

Tools / Onboarding / Cohort · 2026 Q2 / Response 0247

Slash. Quieter, reads like a path. No icon dependency. Risk: at small sizes, separator competes visually with text comma/punctuation.

Variant C · back-arrow (companion, not replacement)

Back to Cohort · 2026 Q2

Back-arrow. Single-step back, mobile-style. Pairs WITH a full crumbs trail on detail screens — not an alternative. Rule: full trail above page title; back-arrow optional on deep detail views where there's a clear "parent".
